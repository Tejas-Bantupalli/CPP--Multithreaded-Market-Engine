# Projects

- **Multithreaded C++ Market Engine:** Designed and implemented a multi-agent market simulator in C++17 with a single-threaded price-time-priority matching engine, lock-free SPSC queues and multicast market-data distribution. Investigated different concurrency and synchronisation approaches, including mutexes, spinlocks and futexes, and benchmarked end-to-end and tail latency. Also developed an LLM-agent interface allowing agents to generate, compile and run C++ trading-strategy plugins.

- **Redis-like In-Memory Database:** Built a high-performance Redis-like database in C++17 with a binary TCP protocol, kqueue-based event loop, pipelining, backpressure, hash tables, AVL trees, TTL expiry and background deletion. Optimised networking, memory management and event processing, achieving over 700k GET/SET operations per second.
